\section{Replication code}\label{sec:app-code}
%======================================================================

The analysis is a set of R scripts. \texttt{main.R} orchestrates the pipeline: it loads and
cleans the CBS microdata (cached beside the raw files), builds the exposure measures, fits every
model, and writes the results to \texttt{outputs/} and the tables to \texttt{paper/tables/};
\texttt{Rscript main.R} reproduces every number in this paper. Each file under
\texttt{scripts/} defines one function; the multi-function robustness chains live under
\texttt{robustness/}. The listings below are the estimation code, grouped by role: data
construction, the exposure measures, the DiD and DDD specifications, the event studies, the
selection bounds, inference, and the calibration and sorting checks. Everything else, the
pipeline orchestration, the wrappers and loops that call the primary functions on subsamples,
the helpers that draw the figures, assemble the tables and export the results, and the secondary
diagnostics, is named in Table~\ref{tab:code-index} with the function it wraps or the place its
number appears. Regressions use \texttt{fixest}; the wild cluster bootstrap uses
\texttt{fwildclusterboot}. The raw CBS microdata are not distributed with the code.
